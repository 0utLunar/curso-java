# Curso de Java

Repositório com os exercícios, exemplos e códigos desenvolvidos durante o curso de Java do **Nélio Alves**.

## 📚 Sobre

Este repositório reúne os códigos desenvolvidos ao longo do curso, servindo como um registro do meu aprendizado e prática com Java.

Aqui estão principalmente:

- 📝 Exercícios das aulas
- 💻 Exemplos e códigos utilizados durante o curso
- 🧪 Testes e experimentos relacionados aos conteúdos estudados
