Este repositório reúne os códigos desenvolvidos ao longo do curso, servindo como um registro do
meu aprendizado e prática com Java.

_This repository gathers the code written throughout the course, serving as a record of my
learning and practice with Java._

## 📁 Organização — _Organization_

Os conteúdos estão organizados em pastas numeradas seguindo a ordem das aulas, do básico ao
avançado. Projetos maiores desenvolvidos durante o curso possuem **repositórios próprios** —
veja [`workshop-springboot4-jpa`](https://github.com/0utLunar/workshop-springboot4-jpa) e
[`demo-dao-jdbc`](https://github.com/0utLunar/demo-dao-jdbc).

_The content is organized in numbered folders following the class order, from basic to advanced.
Larger projects developed during the course have **their own repositories** — see
[`workshop-springboot4-jpa`](https://github.com/0utLunar/workshop-springboot4-jpa) and
[`demo-dao-jdbc`](https://github.com/0utLunar/demo-dao-jdbc)._

## 📝 Notas — _Notes_

- A maior parte dos exercícios é **Java puro** (console, sem framework). Spring e Hibernate
  aparecem apenas em exemplos pontuais.
  _Most exercises are **plain Java** (console, no framework). Spring and Hibernate appear only in
  occasional examples._
- Sem build tool — os exercícios são compilados e executados direto pela IDE, sem `pom.xml`.
  _No build tool — the exercises are compiled and run directly from the IDE, no `pom.xml`._
- Cada pasta é autocontida; não há dependências entre módulos.
  _Each folder is self-contained; there are no cross-module dependencies._
